# GUIA landing page

Sitio estático preparado para GitHub Pages.

## Qué editar antes de publicar

- Sustituir los enlaces de ejemplo dentro de `index.html`:
  - Repositorio GitHub
  - Portal CKAN
  - API / Grafo de conocimiento
  - Servicios de IA
- Sustituir los logos de marcador de posición:
  - `assets/logo_guia.svg`
  - `assets/logo_upm.svg`

## Publicación en GitHub Pages

### Opción simple

Sube el contenido de este zip a la raíz del repositorio y activa GitHub Pages desde la rama principal.

### Si lo publicas en un subpath

Esta versión usa rutas relativas, así que funciona tanto en dominio raíz como en `https://usuario.github.io/repositorio/`.
