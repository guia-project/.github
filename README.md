# GUIA GitHub Pages site

Web estática para publicar el proyecto GUIA en GitHub Pages.

## Uso

1. Copia estos archivos en la raíz del repositorio.
2. Sustituye los enlaces `#` de la sección `Services` por las URLs reales.
3. Edita el email del footer y, si procede, añade logos o fotografías en `assets/img/`.
4. Activa GitHub Pages desde `Settings > Pages` usando la rama principal.

## Estructura

- `index.html`: contenido y secciones Home, Team, Research y Services.
- `assets/css/style.css`: estilos visuales inspirados en una web académica limpia tipo Nebula.
- `assets/js/main.js`: menú móvil, carrusel y búsqueda de servicios.
